# 📸 Put your photos here

Add pictures (e.g. `photos/first-date.jpg`), then reference them in `js/config.js` under `memories`:

```js
{ date: "2023-05-20", title: "First trip to the city", text: "...", photo: "photos/first-date.jpg" },
```

Tip: resize photos to ~1200px wide first so the page loads fast.
